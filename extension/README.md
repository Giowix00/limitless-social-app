# Locked In (Chrome extension)

Load: chrome://extensions > Developer mode > Load unpacked > select this `extension/` folder.
Then fill the options page (opens on install). Details: see the setup steps shown there.

- Camera analysis runs locally (MediaPipe); no video leaves the PC. Only text alerts go to Telegram.
- Alerts: phone in hand, away from desk, hands not visible, left Locked In, camera off.
- Sites in the blocklist are redirected during work hours.
- Test mode ("ignore schedule") lets you try it outside 15:00-19:30.
